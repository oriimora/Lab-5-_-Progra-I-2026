Implementación de estructuras de datos en C: arreglo dinámico, lista enlazada simple,
lista doblemente enlazada y stack (pila).
## Contenido del repositorio

- `include/`: archivos de cabecera (.h) con la interfaz de cada estructura de datos.
- `src/`: implementación (.c) de las funciones de cada estructura de datos.
- `main.c`: programa principal que demuestra el funcionamiento de cada estructura.
- `Makefile`: automatiza la compilación del proyecto.

Estructuras de datos implementadas:
- Arreglo Dinámico (`dynamic_array`)
- Lista Enlazada simple (`linked_list`)
- Lista Doblemente Enlazada (`doubly_linked_list`)
- Stack (`stack`)

## Pasos para compilar

Desde la raíz del proyecto, ejecutar:

"make" : Esto genera el archivo ejecutable `main`.

"make clean" : Para eliminar los archivos generados por la compilación

"./main" : Es para ejecutar despues de compilar.

".\main.exe" : En Windows (PowerShell)
